# river-skills

君秋水的个人技能库。

## 技能

### deep-thinking
基于第一性原理的深度推导。从无可辩驳的事实出发，层层追问到系统元前提。用于复杂决策、因果分析、预测、竞争性解释或高风险问题。不适用简单查询、常规文案、直接代码编辑。

### ai-detective
顶级信息侦探。多源调查，构建证据链，剥离噪声，交叉验证。用户明确说出"AI侦探"或"AI大侦探"时触发。三个定量核验工具：乘积陷阱检验、量纲可比性检验、同一主语两个位置原则。

### connector
在任意两个看似无关的事物之间找到共享的底层结构，用同构规则生成新方案。三步法则：剥开（追问底层规则）、对位（跨领域寻找同构）、重铸（投射生成方案）。适用于创意发想、跨领域类比、结构性问题重构。

### complex-research
研究复杂问题的行动手册。以"理解真实意图"为起点，走完理解、取证、建模、实验、迭代的大闭环，每一步都写进行动记录文档。适用于需要深度调研、证据驱动的复杂问题。

## 使用

克隆到 `.claude/skills` 目录：

```bash
cd ~/.claude/skills
git clone https://github.com/AutumnRiver/river-skills.git
```

技能根据各自触发条件自动启用。详见各技能文件夹内的 SKILL.md。
